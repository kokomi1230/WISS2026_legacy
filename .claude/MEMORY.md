# プロジェクト記憶ファイル (MEMORY.md)

このファイルはチャットをまたいで保持すべき **プロジェクト共有の好み・修正履歴・繰り返しパターン** を蓄積する。Claude は新規セッション開始時に CLAUDE.md と共に本ファイルを読み込み、ここに書かれたルールを適用する。

出典: `docs/CLAUDE_CODE_BEST_PRACTICES.md` Part 3 Step 3 (Miles Deutscher) で紹介された "Memory.MD" 機構の本プロジェクト実装（この解説はテンプレートリポジトリにあり、初期化時に削除される）。

## 役割分担

- **本ファイル (`.claude/MEMORY.md`)** — git 管理・チーム共有スコープ。コミットで他開発者と共有される
- **ハーネス auto-memory (`~/.claude/projects/<encoded>/memory/`)** — 個人・マシン単位スコープ。frontmatter 付きの分割ファイルで管理される。git 管理対象外

書き込み先の判断:

- チームで共有したい好み・規約・修正履歴 → 本ファイル
- 個人の癖・ローカル context・特定マシンでのデバッグ知見 → ハーネス auto-memory

## 更新ルール

- 追記前に **既存項目を grep して重複しないこと**
- CLAUDE.md に既に明文化されているルールは記録しない（重複を避ける）
- 一時的なタスク状態・コード固有のバグ修正は記録しない（PR / コミットメッセージで残す）
- 各エントリは 1 行〜数行で簡潔に。長文化したら別ドキュメントへ昇格する
- 更新は `memory-update` skill のガイドに従う

## Preferences

ユーザーが好む書き方・出力フォーマット・スタイル。

- コードコメントは日本語で書く（識別子自体は各言語の慣習どおり英語のままでよい）
- 冗長なデバッグログ（本番残置の print/console.log 等の逐次トレース出力）を避ける
- 冗長な説明（同じ内容を複数箇所で言い換えて繰り返す）を避ける。コード・ドキュメント問わず適用
- コーディング規約（命名規則・コメントの付け方）は CLAUDE.md/README.md/.claude/MEMORY.md と自作 skill/agent の Markdown にも適用する（vendored skill・`_archived/` は対象外）
- 論文本文はシステム仕様書にしない。パラメータ名・コード識別子・変数名・実装固有語（例「遅延注入」「UDP」「CSV」）を本文に出さず、機構と設計判断を抽象度を保った日本語で述べる
- トピックセンテンスは「その段落の主張を言い切った一文」にする。「何について書くか」の内容説明にしない。数値・出典・根拠は一文に詰め込まず別列（表）に分離する
- 論文構成・解説資料の成果物は原則 HTML 形式で作る（プロジェクト内の既存 `*.html` と同系統の自己完結 HTML）

## Corrections

過去にユーザーから訂正された事項、および **Claude 自身が繰り返したミスとその解決策**。再発防止用。

記録フォーマット（1 エントリ＝根本原因＋解決策を簡潔に）:

- **避ける:** <やってしまったこと> / **目指す:** <正しいやり方>（理由: <根本原因>）

<!-- 例:
- **避ける:** `mkdir -p` を確認なしに実行 / **目指す:** ディレクトリ作成前に親ディレクトリの存在を確認する
- **避ける:** SKILL.md 編集後に CATALOG 同期を忘れる / **目指す:** 編集後に `sync-catalogs.sh --check` で drift 確認（理由: hook は外部編集を取りこぼす）
-->

- **避ける:** `apply_profile.py --write-claude-md` を実行して結果を検証しない / **目指す:** 実行後に `## プロジェクト規約` 以降が残っているか grep で確認し、消えていたら復元する（理由: スクリプトは保存境界を `## クイックスタート` の正規表現で探すが、本テンプレートの CLAUDE.md は `## プロジェクト規約` を境界に使うためアンカー不一致でファイル全体が置換され、規約セクションが丸ごと消える。2026-08-14 の /init-project で実際に発生し原本から手動復元した）
- **避ける:** `apply_profile.py` を素の `python3` で実行 / **目指す:** `CLAUDE_PROJECT_DIR=<プロジェクト絶対パス>` を前置する（理由: 未設定だと `~/.claude` を project root と誤認し「profile not found」になる）

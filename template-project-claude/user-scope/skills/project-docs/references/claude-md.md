# CLAUDE.md の書き方

## 何を含め、何を除くか

公式ドキュメントの分類をそのまま使う。各行に「これを消したら Claude は間違えるか」を問い、No なら消す。

| 含める | 除く |
|---|---|
| 推測できないコマンド（ビルド / テスト / 実行の実際の呼び出し） | コードを読めば分かること |
| 既定と異なる規約 | その言語の標準的な慣習 |
| テストの実行方法と使うランナー | API リファレンス（リンクで足りる） |
| リポジトリの作法（ブランチ名、PR の規約） | 頻繁に変わる情報 |
| このプロジェクト固有の設計判断 | 長い解説・チュートリアル |
| 開発環境の癖（必要な環境変数） | ファイル単位のコードベース説明 |
| 非自明な落とし穴 | 「きれいなコードを書く」のような自明な心構え |

**除外側が肥大の主因である。** ディレクトリの逐次説明・導入手順・機構の解説は、どれも「コードや README を読めば分かること」に当たる。

## 行数

- **200 行未満が目標。** 公式ドキュメントの明示値。超えると指示の遵守率が落ちる
- **250 行が上限。** これを超えると人も Claude も読み飛ばす

行数が超えたときに**削るのではなく移す**。移し先は下の 3 つ。

1. 特定のファイル種別でだけ要るもの → `.claude/rules/<topic>.md`（`paths:` 付き）
2. 特定の作業でだけ要るもの → skill
3. 人間向けの説明 → `README.md` または `docs/`

## falsifiable に書く

判定できないルールは守られたかどうかも分からない。

**避ける:** 良いコードを書く / 適切にエラー処理する / パフォーマンスに配慮する
**目指す:** `any` を使わない / `async` 関数にはタイムアウトを付ける / 1 ファイル 300 行を超えたら分割する

「IMPORTANT」「必ず」などの強調は遵守率を上げるが、多用すると効かなくなる。本当に例外を許さないものだけに使う。例外を一切許さないなら、CLAUDE.md ではなく hook で機械的に止める。

## .claude/rules/ への切り出し

`paths:` frontmatter を付けると、**該当するファイルを読んだときだけ**ロードされる。これが CLAUDE.md を縮める唯一のレバーである。

```markdown
---
paths:
  - "src/api/**/*.ts"
---

# API の規約

- すべてのエンドポイントで入力を検証する
- エラー応答の形式を統一する
```

- `paths:` が**無い** rule は起動時に無条件ロードされる。CLAUDE.md に書くのと変わらない
- 1 ファイル 1 トピック。ファイル名を見て何の規約か分かるようにする
- glob は `**/*.ts` `src/**/*` `*.md` のように書く

## @path import を使わない

`@path/to/file.md` は import 先を**起動時に全ロード**する。ファイルを分けられるので整理にはなるが、**コンテキストは 1 バイトも減らない**。節約が目的なら `paths:` を使う。

パスを本文で言及したいだけならバッククォートで囲む。`` `@README` `` は import されないが、`@README` は import される。

## その他の仕様

- **ブロック HTML コメント（`<!-- ... -->`）は context 注入前に除去される。** 保守者向けのメモをトークンを消費せずに残せる
- **プロジェクトルートの CLAUDE.md は compaction を生き延びる。** `/compact` 後に再読込されるが、サブディレクトリの CLAUDE.md は再注入されない
- 配置先は `./CLAUDE.md` または `./.claude/CLAUDE.md`。個人設定は `./CLAUDE.local.md`（`.gitignore` 対象）

## 構成の型

決まった書式は無い。次は 200 行に収まりやすい並びである。

```
# <プロジェクト名>
<1 段落の概要。何であって誰のためのものか>

## 常用コマンド
<ビルド / テスト / 実行の実コマンド。最も効く節>

## 規約
<既定と異なるものだけ。falsifiable に>

## 設計上の判断
<なぜそうなっているか。コードから読み取れない理由>

## 落とし穴
<非自明な挙動、踏みやすい罠>
```
